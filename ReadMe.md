
TO RUN THE PROJECT:
-make sure youre inside the project folder  Test2
-run npm install on the terminal

The Firebase setup and configuration are located in Firebase.js file




Packages :
        npm install firebase
        npm install @react-navigation/native
        npm install @react-navigation/stack
        npm install @react-navigation/bottom-tabs
        npm install @react-native-async-storage async-storage
        npm install react-native-screens react-native-safe-area-context

Features Covered:
        Firebase Authentication (Signup / Login / Logout)
        Realtime Database for user-specific carts
        Add, remove, and update cart items
        Local storage with AsyncStorage for offline use
        React Navigation (Products → Details → Cart)
        Clean responsive UI using Flexbox and StyleSheet
